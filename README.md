# Tandau

## О проекте

Сервис помогает организаторам мероприятий быстрее найти подходящего подрядчика по городу, категории услуги, дате, формату, бюджету и дополнительным требованиям. Он показывает до трёх профилей и объясняет, какие условия запроса они выполняют. Решение создано в рамках хакатона Vision2026.

## Что реализовано

- Каталог подрядчиков загружается из CSV и проверяется при чтении: валидируются идентификаторы, цены, даты, длительность и булевы признаки.
- Подбор учитывает город и категорию, занятость на выбранную дату, цену «от», формат мероприятия, язык и максимальную длительность работы.
- Подходящие профили сортируются по упоминанию формата в описании, затем по цене и идентификатору. В ответ попадают не более трёх карточек.
- Результат различает три состояния: найдены подходящие профили (`matched`), категория отсутствует в выбранном городе (`category_absent`), либо категория есть, но кандидаты не прошли условия (`no_match`). Для последнего состояния возвращается счётчик причин отказа.
- В карточке показываются имя профиля, категория, город, цена «от», объяснение, флаг синтетического профиля и признаки восстановленных данных.
- Streamlit-интерфейс содержит форму запроса и три демонстрационных запроса: популярная категория, редкая категория и бюджет ниже цены подрядчиков.
- FastAPI предоставляет отдельный HTTP API для проверки состояния, просмотра вариантов и отправки запроса на подбор.
- При доступной конфигурации AI-сервис выбирает подтверждающий факт из описания профиля. При ошибке API или некорректном ответе подбор сохраняет объяснение, построенное правилами.

## Как работает решение

1. Пользователь выбирает город, категорию, формат, дату и бюджет; при необходимости указывает язык и длительность.
2. Приложение передаёт эти значения существующей функции подбора вместе с загруженным каталогом.
3. Алгоритм сначала находит профили нужной категории в городе, затем исключает занятые на дату или не прошедшие остальные условия.
4. До трёх оставшихся профилей ранжируются и возвращаются вместе с объяснениями. Если профилей нет, интерфейс сообщает, отсутствует ли сама категория в городе или кандидаты не подошли по условиям.

Streamlit вызывает Python-функцию подбора напрямую. Запуск FastAPI нужен для отдельного HTTP API и не является обязательным для локального интерфейса.

## Технологии

- **Язык:** Python.
- **Интерфейс:** Streamlit.
- **HTTP API:** FastAPI, Uvicorn, Pydantic 2; настроен CORS для локальных адресов.
- **Данные:** CSV, стандартные модули Python `csv`, `datetime`, `pathlib`.
- **AI:** OpenAI Responses API через библиотеку `openai`. Конкретная модель задаётся переменной `OPENAI_MODEL`; идентификатор модели в репозитории не зафиксирован. `python-dotenv` загружает переменные из `.env`.
- **Внешние сервисы:** OpenAI API используется только для выбора факта из описания профиля. Сам подбор и фильтрация выполняются локальным Python-кодом.

## Архитектура

```text
frontend/streamlit_app.py
    ├── frontend/demo_queries.py
    ├── backend/loader.py ── backend/data/contactors.csv
    └── backend/recommender.py
            └── backend/ai_explanations.py ── backend/ai_client.py ── OpenAI API (необязательно)

backend/app.py ── FastAPI endpoints ── backend/loader.py + backend/recommender.py
```

- `backend/loader.py` читает CSV относительно расположения самого модуля, поэтому запускать приложения следует из корня репозитория.
- `backend/recommender.py` содержит фильтрацию, ранжирование и построение результата.
- `backend/app.py` при старте загружает каталог и открывает HTTP-маршруты `/health`, `/options` и `POST /recommend`.
- `frontend/streamlit_app.py` загружает каталог, формирует форму и напрямую передаёт запрос функции `recommend`.
- `frontend/ui_components.py` отображает статусы, ошибки и карточки; `frontend/demo_queries.py` хранит примеры для демонстрации.

## Установка и запуск

Требуется Python 3.10 или новее. Команды ниже приведены для запуска из корня проекта.

### Streamlit-интерфейс

Создайте и активируйте виртуальное окружение, затем установите зависимости проекта и Streamlit:

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt streamlit
streamlit run frontend/streamlit_app.py
```

macOS / Linux:

```bash
source .venv/bin/activate
python -m pip install -r requirements.txt streamlit
streamlit run frontend/streamlit_app.py
```

Streamlit намеренно указан отдельным пакетом в команде установки: в текущем `requirements.txt` его нет.

### HTTP API (необязательно для Streamlit)

При активированном окружении:

```bash
python -m pip install -r requirements.txt
uvicorn backend.app:app --reload
```

API будет доступен по адресу `http://127.0.0.1:8000`; интерактивная документация FastAPI — `http://127.0.0.1:8000/docs`.

Для улучшения объяснений создайте файл `.env` в корне проекта со значениями:

```dotenv
OPENAI_API_KEY=ваш_ключ
OPENAI_MODEL=имя_доступной_модели
```

Без ключа или при недоступности API подбор работает с объяснениями по правилам. Не публикуйте `.env` и API-ключ.

## Как проверить решение

1. Установите зависимости и запустите Streamlit командой выше.
2. В списке «Демо-запрос» выберите популярную категорию и нажмите «Подобрать». Проверьте карточки: имя, категория, город, цена от, объяснение и отметка синтетического профиля, если она применима.
3. Повторите для редкой категории. Это показывает, как интерфейс отображает малое число совпадений или отсутствие подходящих профилей.
4. Выберите демо-запрос с бюджетом ниже цены и нажмите «Подобрать». Ожидается статус, что категория в городе есть, но кандидаты не проходят условия, с причинами отказа.
5. Чтобы проверить API отдельно, запустите Uvicorn и откройте `/docs`. В `POST /recommend` передайте, например:

```json
{
  "city": "Алматы",
  "date": "2026-10-15",
  "event_format": "корпоратив",
  "category": "Ведущий",
  "budget_kzt": 700000,
  "duration_hours": 5,
  "language": "русский"
}
```

Ограничения входа API: дата должна быть в диапазоне `2026-09-23` — `2026-12-31`; бюджет и заданная длительность должны быть положительными числами.

## Данные и интеграции

Основной источник — локальный файл `backend/data/contactors.csv` (именно такое написание имени файла используется в проекте). В нём хранятся псевдоним профиля, город, категории, форматы, языки, цена «от» в тенге, максимальная длительность, занятые даты, описание и флаги синтетических или восстановленных данных. Несколько значений в поле CSV разделяются символом `|`.

Интернет-каталог или внешняя база подрядчиков в текущей версии не подключены. OpenAI API — единственная внешняя интеграция; она не принимает решение о соответствии фильтрам и не обязательна для запуска подбора.

## Ограничения текущей версии

- Данные каталога статичны и поставляются в CSV; редактирование профилей через интерфейс не реализовано.
- Диапазон дат задан константами в backend и ограничен периодом с 23 сентября по 31 декабря 2026 года.
- В карточках показываются только первые три ранжированных результата.
- Цена «от» используется как нижняя граница оценки и не является окончательной сметой или подтверждением доступности подрядчика.
- Для синтетических профилей и восстановленных данных предусмотрены отдельные признаки; данные нужно трактовать соответственно.
- AI-зависимость необязательна, но для обращения к OpenAI нужны действительные ключ и имя модели. Идентификатор модели не закреплён в проекте.
- В `requirements.txt` отсутствует Streamlit, поэтому его необходимо устанавливать отдельно указанной командой.
- Авторизация, роли пользователей, хранение истории запросов, онлайн-бронирование и развертывание в облаке не реализованы.
